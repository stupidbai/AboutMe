# index.html 版本快照

本目录保存已经发布的 `index.html` 物理快照。快照文件一经提交不得覆盖；新版本应新增文件，并保留旧文件。

## 版本清单

| 文件 | 版本 | 内容定位 | 来源 |
| --- | --- | --- | --- |
| `index-v1.1.0-求职简历.html` | v1.1.0 | AI 技术总监 / AI 应用架构师求职简历 | Git 标签 `v1.1.0` |
| `index-v2.0.0-商业合作版.html` | v2.0.0 | 企业 AI 商业合作伙伴介绍 | Git 标签 `v2.0.0` |
| `index-v2.0.1-商业合作版.html` | v2.0.1 | 移除南京邮电大学背书标签的商业合作版 | Git 标签 `v2.0.1` |

`v1.0.0` 和 `v1.1.0` 的 HTML 内容完全相同，所以没有重复保存两份物理文件。

## 使用规则

1. 根目录 `index.html` 始终代表当前对外版本。
2. 修改当前页面前，确认当前发布版已经保存在本目录。
3. 发布新版本时新增 `index-vX.Y.Z-名称.html`，禁止覆盖旧快照。
4. 同步更新 `manifest.json`、根目录 `CHANGELOG.md`，并创建对应 Git 标签。
5. 对外发送历史版本时直接使用本目录对应文件，不要临时回滚根目录文件。
